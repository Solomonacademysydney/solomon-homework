04 — FAQ

Common questions.

How does it work? / 어떻게 진행되나요?

Every day from Monday to Friday, your child receives a learning set (about 30–40 minutes) on the Solomon platform. Once a week, the principal runs a live coaching session reviewing the week's content. Parents receive a monthly report summarising progress.

평일(월~금) 매일 약 30-40분 분량의 학습 세트가 Solomon 플랫폼에 제공됩니다. 주 1회 원장이 직접 진행하는 라이브 수업에서 한 주 내용을 정리합니다. 매월 학부모 리포트로 진도와 약점을 공유드립니다.

What's the refund policy? / 환불 정책은?

First 14 days: full refund, no questions asked. After that, we run on monthly cycles — you can stop at the end of any month with no further charge.

첫 14일: 무조건 전액 환불. 이후엔 월 단위로 운영되며, 어느 달이든 월말 종료 가능합니다. 장기 계약 강요 없습니다.

How is this different from in-person? / 오프라인이랑 차이가 뭔가요?

Same curriculum, same principal, same depth — but daily instead of once a week. Live coaching replaces the in-person classroom. Best for families outside Sydney or those preferring flexible scheduling.

커리큘럼, 원장, 깊이는 동일합니다. 다만 주 1회 오프라인 수업 대신 매일 학습 + 주 1회 라이브로 진행됩니다. 시드니 외 지역 거주자나 시간 유연성이 필요한 가정에 적합합니다.

What if my child falls behind? / 혼자 따라가지 못하면?

Three-tier hint system on every question (nudge → method → full solution). Wrong answers trigger targeted follow-up practice on the same concept. Parents can message the principal directly via KakaoTalk for any concern.

모든 문제에 3단계 힌트 시스템이 있습니다 (살짝 → 방법 → 풀이). 오답이 발생하면 같은 개념의 보강 문제가 자동으로 제공됩니다. 걱정되시면 카카오톡으로 원장에게 직접 문의 가능합니다.

Are textbooks included? / 교재는 별도 구매인가요?

Everything is included in the monthly fee — daily content, live sessions, platform access, and reports. No additional textbook purchases required.

매월 수강료에 모든 것이 포함됩니다 — 매일 학습 콘텐츠, 라이브 수업, 플랫폼 접근, 리포트. 별도 교재 구매 필요 없습니다.

Can students in Korea join? / 한국 거주 학생도 가능한가요?

Yes — as long as the family can join the weekly live session (Australian Eastern time). Daily content can be done at any time. We'll confirm the live time after enrolment to fit your timezone.

가능합니다 — 단, 주 1회 라이브 수업 시간(호주 동부 시간 기준)에 참여할 수 있어야 합니다. 매일 학습은 시간 자유. 등록 후 원장님과 시간대 협의합니다.
